# Roadmap Poza Szumem

## Wdrozone w tej iteracji

- [x] Bezpieczne ustawienia motywu i walidacja zapisanych fragmentow.
- [x] Spojne wersjonowanie zasobow, limit oczekiwania sieci i fallback offline.
- [x] Zachowanie pobranych artykulow przy aktualizacji aplikacji.
- [x] Kompaktowa biblioteka, widok kart/listy i sortowanie.
- [x] Zachowanie filtrow i miejsca po powrocie z tekstu.
- [x] Zapisywanie calych artykulow niezaleznie od fragmentow.
- [x] Czytaj dalej, wznawianie od akapitu i opcja rozpoczecia od poczatku.
- [x] Rozmiar tekstu takze poza trybem skupienia.
- [x] Mocniejszy kontrast, fokus klawiatury i dostepne panele.
- [x] Wspolny generator publikacji z HTML i Markdown.
- [x] Automatyczne czasy czytania, autor/wydawca, srodtytuly i dalsza lektura.
- [x] Podstrony kategorii i serii, wybor tygodnia.
- [x] Canonical, Article/Open Graph, obraz udostepniania, RSS i sitemap.
- [x] Walidacja linkow i testy przegladarkowe przed publikacja.

## Odlozone decyzja wlasciciela

- Newsletter i zbieranie adresow e-mail.

## Dalszy rozwoj

- Pelna weryfikacja faktow oraz rozbudowa bibliografii poszczegolnych artykulow.
- Dodatkowe przegladarki: Safari/WebKit i Firefox.
- Konta i synchronizacja tylko po potwierdzeniu potrzeby przez czytelnikow.
- Pomiary uzytecznosci i wydajnosci na rzeczywistych urzadzeniach.
